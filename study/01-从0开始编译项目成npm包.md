# 从0开始编译整个项目成为一个npm包

本文档介绍如何从零开始将 OpenClaw 项目编译打包成为一个可发布的 npm 包。

## 环境要求

- Node.js 22+ （推荐使用 Node 22 或更高版本）
- pnpm 包管理器（项目使用 pnpm 管理依赖）
- Git

## 第一步：获取源代码

```bash
# 克隆项目
git clone https://github.com/你的用户名/openclaw_local.git
cd openclaw_local

# 如果需要同步官方最新代码
git remote add upstream https://github.com/openclaw/openclaw.git
git fetch upstream
git merge upstream/main
```

## 第二步：安装依赖

```bash
# 使用 pnpm 安装所有依赖
pnpm install
```

> 也支持使用 bun：
> ```bash
> bun install
> ```

## 第三步：执行编译构建

项目使用 TypeScript 开发，需要编译为 JavaScript 才能使用。

```bash
# 执行完整构建（包含类型检查和编译）
pnpm build
```

构建完成后，输出文件会生成在 `dist/` 目录下。

## 第四步：类型检查（可选但推荐）

```bash
# 运行 TypeScript 类型检查
pnpm tsgo
```

## 第五步：代码检查和格式化（可选）

```bash
# 运行 lint 检查和格式检查
pnpm check

# 自动修复格式问题
pnpm format:fix
```

## 第六步：运行测试（可选）

```bash
# 运行所有测试
pnpm test
```

## 第七步：打包为 npm 包

### 查看当前版本

在 `package.json` 中查看 `version` 字段，确认版本号。

### 打包

```bash
# 使用 npm pack 打包生成 tar.gz 压缩包
npm pack
```

执行完成后，会在项目根目录生成类似 `openclaw-xxxx.x.x.tgz` 的压缩包，这就是完整的 npm 包。

### （可选）发布到 npm

如果你有权限发布到 npm，可以执行：

```bash
# 登录 npm（需要先注册 npm 账号）
npm login

# 发布
npm publish --access public
```

> 注意：根据项目规范，OpenClaw 核心版本发布使用 GitHub 信任发布，不需要 NPM_TOKEN。

## 第八步：验证打包结果

可以在其他目录测试安装你打包的 npm 包：

```bash
# 创建测试目录
mkdir test-package && cd test-package
npm init -y

# 安装本地打包的 npm 包
npm install ../openclaw/openclaw-xxxx.x.x.tgz

# 测试命令
npx openclaw --help
```

## 输出文件说明

- `dist/` - 编译后的 JavaScript 代码
- `openclaw-<version>.tgz` - npm 打包文件，包含所有必需的编译产物
- `package.json` - 包信息，已经包含正确的入口点

## 常见问题

### 1. 依赖安装失败

**解决方法：**
```bash
# 清除缓存重新安装
rm -rf node_modules
rm pnpm-lock.yaml
pnpm install
```

### 2. 构建时出现类型错误

**解决方法：**
- 检查 Node.js 版本是否为 22+
- 执行 `pnpm install` 重新安装依赖
- 查看错误信息，根据提示修复类型问题

### 3. 打包后无法运行命令

**解决方法：**
- 确认 `package.json` 中的 `bin` 字段配置正确
- 确认 `dist/` 目录存在且文件已编译完成

## 相关命令总结

| 命令 | 作用 |
|------|------|
| `pnpm install` | 安装依赖 |
| `pnpm build` | 编译构建 |
| `pnpm tsgo` | TypeScript 类型检查 |
| `pnpm check` | 代码检查 |
| `pnpm test` | 运行测试 |
| `npm pack` | 打包为 npm 包 |
| `npm publish` | 发布到 npm |
